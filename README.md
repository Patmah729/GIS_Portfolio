# GIS_Portfolio
A short portfolio of my recent GIS work.

Located in this repository are three projects I've created using GIS.
1. I programmed a GIS-based wildfire simulation model in Python, packaged as a geoprocessing tool in ArcGIS Pro. The output is visible in the modeledmap.gif file. Additional information about this project is available at [this repository](https://github.com/Patmah729/CellularFireModeling/tree/main)
2. I've am a contributor to the Longhorn Council Property Vision Committee. My work for this team consists of maintaining an online spatial database and map which is used in communicating and planning potential property improvements.
